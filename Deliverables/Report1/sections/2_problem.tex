\section{Problem Analysis}

This section presents a detailed examination of the dataset and the underlying learning problem. We characterize the structure and statistical properties of the input signals, identify the primary challenges associated with multivariate temporal modeling, and outline the assumptions that guide our architectural and methodological decisions.

\subsection{Dataset Characteristics}

The dataset is composed of $n$ multivariate time series $\{X_i\}_{i=1}^n$, each of fixed temporal length $T = 160$ and dimensionality $F = 34$.  
Formally,
\[
    X_i \in \mathbb{R}^{F \times T}, \qquad y_i \in \{0,1,2\}.
\]

The feature space can be partitioned into three semantically distinct groups:

\begin{itemize}
    \item \textbf{Survey-derived channels (4 features):}  
    Rule-based pain estimators extracted from simple aggregations. These channels often exhibit coarse temporal variability and may encode subjective or low-resolution information.

    \item \textbf{Biomechanical sensor channels (30 features):}  
    High-frequency continuous measurements of joint kinematics (e.g., neck, elbow, knee). These tend to dominate the temporal structure and contain fine-grained motion patterns.

    \item \textbf{Global static features (3 features):}  
    Subject-specific descriptors that remain constant over time and may correlate with pain response trends.
\end{itemize}

\noindent Label distribution is mildly imbalanced, with the \textit{High Pain} class typically underrepresented. Class imbalance directly impacts training, motivating the use of weighted loss functions and stratified K-fold cross-validation.

\subsection{Main Challenges}

The problem exhibits several key challenges:

\paragraph{1. Temporal and Multivariate Complexity.}
The model must jointly capture long-range dependencies and cross-channel interactions.  
Given the dimensionality
\[
    X_i \in \mathbb{R}^{34 \times 160},
\]
each sample contains $5{,}440$ values, making the learning problem high-dimensional despite the moderate dataset size.

\paragraph{2. Heterogeneous Feature Types.}
Survey channels, biomechanical signals, and global features have fundamentally different statistical properties. A single model must integrate:
\begin{itemize}
    \item low-frequency subjective indicators,
    \item high-frequency sensor signals,
    \item time-invariant metadata.
\end{itemize}

\paragraph{3. Limited Dataset Size.}
Deep architectures with many parameters risk overfitting. This necessitates strong regularization, robust cross-validation, careful hyperparameter tuning, and architectural constraints.

\paragraph{4. Class Imbalance.}
The imbalance across $\{0,1,2\}$ labels affects gradient dynamics and may bias predictions toward frequent classes. We mitigate this through inverse-frequency class weights and stratified folds.

\paragraph{5. Absence of Pretrained Models.}
Unlike domains such as vision or language—where pretrained encoders exist—pain-level estimation from kinematic time series lacks established pretrained backbones. Models must therefore be trained entirely from scratch.

\subsection{Initial Assumptions}

The design of our approach is based on the following assumptions:

\begin{enumerate}
    \item \textbf{Pain-related patterns manifest in temporal dynamics.}  
    We assume that pain levels are reflected not only in static body positions but primarily in temporal trends, variability, and motion irregularities.

    \item \textbf{Multiscale information is critical.}  
    Temporal dynamics may appear at different resolutions (slow posture drifts vs.\ fast joint oscillations). This motivates the exploration of convolutional and multiscale encoders.

    \item \textbf{Global static features act as priors.}  
    Subject-specific metadata may shift the probability distribution over pain classes and should be integrated with the dynamic representation.

    \item \textbf{Dimensionality reduction can improve generalization.}  
    PCA/POD projections may capture dominant dynamical modes, reduce redundancy, and stabilize the learning process.

    \item \textbf{Cross-validation is essential.}  
    Given the dataset size, reliable performance estimates require K-fold validation rather than a single train/validation split.
\end{enumerate}

\noindent These considerations guided the development of a modular preprocessing pipeline and a flexible architecture search framework, described in detail in the subsequent sections.
