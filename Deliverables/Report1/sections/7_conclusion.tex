
\section{Conclusions}
\vspace{-10pt}
We presented our solution for this classification task. 
Although the software package is designed to be general, this generality results in a large hyperparameter search space. Given the time constraints and the associated curse of dimensionality, exhaustive exploration was not feasible.

Although we achieved a high test F1-score (0.9480), we expect that with more time for hyperparameter exploration the performance could improve further. Future work may include integrating attention-based encoders, enlarging the dataset, or augmenting it with synthetic expert-generated trajectories to better handle underrepresented classes.
